# FuelPath PRO - Fuel Cost & Trip Telemetry Calculator\n\nProduction-ready fuel economy, inter-city route planner, FASTag toll estimator, tank range telemetry, and UPI split application.\n\n## 🚀 Quickstart\n\n1. **Install Dependencies:**\n   ```bash\n   npm install\n   ```\n\n2. **Start Development Server:**\n   ```bash\n   npm run dev\n   ```\n\n3. **Build for Production:**\n   ```bash\n   npm run build\n   ```\n\n## 📦 Features\n- Multi-Currency & Dual Unit conversion (INR ₹, USD $, EUR €, GBP £, CAD, AUD, AED, JPY)\n- Live Inter-City Highway & Expressway Planner with FASTag toll estimations and waypoints\n- Real-time City Fuel Price Index across 50+ Indian and International Metros\n- Tank Autonomy, Highway Refill calculation, and Fuel Drain Telemetry\n- Group Expense Splitting with Deep Link UPI and QR Generation (GPay, PhonePe, Paytm, BHIM)\n- Offline-first PWA caching and Local Persistence for Trip Logs with CSV export\n- App Store & Google Play Privacy Policy compliance\n\nDeveloped with React 19, TypeScript, Tailwind CSS, and Vite.
