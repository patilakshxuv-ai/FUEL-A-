# FuelPath PRO - Fuel Cost & Trip Telemetry Calculator

Production-ready fuel economy, inter-city route planner, FASTag toll estimator, tank range telemetry, and UPI split application.

## 🚀 Quickstart

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

## 📦 Features
- Multi-Currency & Dual Unit conversion (INR ₹, USD $, EUR €, GBP £, CAD, AUD, AED, JPY)
- Live Inter-City Highway & Expressway Planner with FASTag toll estimations and waypoints
- Real-time City Fuel Price Index across 50+ Indian and International Metros
- Tank Autonomy, Highway Refill calculation, and Fuel Drain Telemetry
- Group Expense Splitting with Deep Link UPI and QR Generation (GPay, PhonePe, Paytm, BHIM)
- Offline-first PWA caching and Local Persistence for Trip Logs with CSV export
- App Store & Google Play Privacy Policy compliance

Developed with React 19, TypeScript, Tailwind CSS, and Vite.
